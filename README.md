Website manajemen Sweet Bakery & Cafe yang dibuat menggunakan framework Laravel Murni tanpa koneksi database.
## Fitur Utama
- Simulasi login:Meneruskan data nama/username penguna dari form login ke halaman Dashboard dan Profile melalui Request Parameter.
- Dashboard: Statistik ringkasan toko yang meliputi menu, rating dan orderan.
- Pengelolaan Menu: Menampilkan katalog menu kue dan pastry dari Controller ke View menggunakan perulangan Blade.
- Profil: Melihat identitas pengguna.
